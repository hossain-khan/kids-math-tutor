## Best Practices for Release Notes

### DO:
✅ Start with most exciting feature
✅ Use emojis for visual appeal (kid-friendly app!)
✅ Keep it under 500 characters for short version
✅ Mention new badges (motivates engagement)
✅ Thank users
✅ End with mascot emoji 🐶

### DON'T:
❌ Use technical jargon
❌ List every minor change
❌ Include version numbers in description
❌ Mention bugs that users didn't notice
❌ Use ALL CAPS excessively
❌ Be negative or apologetic

### Keywords to Include (for ASO):
- math
- learning
- kids
- practice
- games
- badges
- educational

## Localization Notes

When localizing release notes:

### Spanish (es)
- "Happy learning!" → "¡Feliz aprendizaje!"
- "Bug fixes" → "Corrección de errores"
- Keep emoji universal

### French (fr)
- "Happy learning!" → "Bon apprentissage!"
- "New features" → "Nouvelles fonctionnalités"

### German (de)
- "Happy learning!" → "Viel Spaß beim Lernen!"
- "Bug fixes" → "Fehlerbehebungen"
